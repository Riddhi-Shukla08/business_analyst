# business_analyst
Sales &amp; Profit Analysis using Excel — data cleaning, Pivot Tables, KPI analysis, charts, and an interactive dashboard to identify sales and profit trends.
Sales & Profit Analysis using Excel

📌 Project Overview

This project analyzes sales and profit data using Microsoft Excel. The goal is to clean the dataset, identify important business insights, and present the results through Pivot Tables, KPIs, charts, and an interactive dashboard.

🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Charts
- KPI Analysis
- Data Cleaning

📊 Project Work

- Cleaned and organized the dataset
- Created Pivot Tables for analysis
- Analyzed sales and profit by category
- Analyzed sales and profit by region
- Analyzed sales and profit by segment
- Created monthly sales analysis
- Created KPI Summary
- Created charts for data visualization
- Designed a final Sales & Profit Dashboard

📈 Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Average Sales

🎯 Objective

The main objective of this project is to understand sales performance, identify profitable areas, and present business insights in an easy-to-understand dashboard.
